# Portfolio Direction

## Approved direction

Create a modern, focused personal-portfolio redesign that presents Azeezat's work, strengths, and contact path clearly. The site should be responsive, accessible, fast to load, and easy to maintain.

## Technical approach

- Prefer semantic HTML, CSS, and small, purposeful vanilla JavaScript.
- Do not add a framework or build tooling unless a concrete requirement justifies it.
- Use progressive enhancement and respect reduced-motion preferences.

## Isolation safeguards

- This is a separate project from `Zeezoh22/azeezat-portfolio`.
- Never copy, reuse, or create `.vercel` metadata from the existing portfolio.
- Do not modify, push to, deploy, or reconfigure the existing portfolio or its Vercel project.
- Treat any future GitHub and Vercel connections as new resources for this redesign only.
